# ton_connect

Pure Dart implementation of the [TON Connect 2](https://github.com/ton-blockchain/ton-connect) protocol: encrypted HTTP bridge sessions, the injected JS bridge, the wallet registry and universal links.

> **Status: early development.** Not yet usable end-to-end and not yet published. See the [repository README](https://github.com/Treamz/ton_connect_dart) for the roadmap.

Implements the protocol as of revision **2026.05.18**, including `signMessage`, structured transaction items, `NETWORK_ID`, `EmbeddedRequest` and `trace_id`.
